# AI Usage Documentation

## Tool used

ChatGPT was used to help draft this beginner-friendly PostgreSQL Library Management System project.

## Prompts used

The main prompt was: “Build a complete PostgreSQL database project for a Library Management System with users, books, categories, and borrowings. Include schema, sample data, CRUD, joins, grouping, pagination, transactions, indexes with EXPLAIN ANALYZE, documentation, and beginner-friendly comments.”

Follow-up instructions requested PostgreSQL-compatible SQL, realistic data, separate project files, and execution verification when PostgreSQL is available.

## AI-generated assistance

ChatGPT helped generate:

- The table design, keys, relationships, data types, and constraints.
- Sample categories, members, books, and borrowing records.
- Demonstration queries for CRUD, joins, grouping, pagination, transactions, and index analysis.
- The README and explanatory SQL comments.

## Manual changes and verification

The project structure and SQL were reviewed manually for PostgreSQL syntax and logical consistency. In this workspace, the PostgreSQL `psql` client was not available, so the SQL was **not executed here**.
